# Audio Files

Add your audio recordings to this folder.

## File Naming Convention

Name each audio file to match its corresponding number:
- `1.mp3` - Audio for message #1
- `2.mp3` - Audio for message #2
- `3.mp3` - Audio for message #3
- ... and so on up to ...
- `25.mp3` - Audio for message #25

## Supported Formats

MP3 format is recommended for best browser compatibility.

## Notes

- The wheel will work without audio files - it will just display the messages without sound
- Audio files will play automatically when the wheel lands on that number
